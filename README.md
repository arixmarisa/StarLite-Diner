# StarLite Diner

StarLite Diner is a retro pixel-art browser game where you play as a diner worker. Explore the dining room and kitchen, take orders from customers, and collect their orders in your notepad.

Built at YCP Hacks 2026, where it won **Best Gaming Hack (Retro Theme)** and **MLH Best Use of GoDaddy Registry**.

[View StarLite Diner on Devpost](https://devpost.com/software/project-rymcbi2hx6ov)

## How to play

Install Node.js 22.12+ (22.x) and npm 10.x, then run:

```bash
git clone https://github.com/arixmarisa/StarLite-Diner.git
cd StarLite-Diner
npm ci
npm run dev
```

1. Open [http://localhost:5173](http://localhost:5173) in your browser and click **Start**.
2. Move with **WASD** or the **arrow keys**.
3. Walk up to a table marked with **!** and press **E** to take the customers’ orders. The ticket is added to your notepad automatically.
4. Walk through either door at the back of the dining room to enter the kitchen.
