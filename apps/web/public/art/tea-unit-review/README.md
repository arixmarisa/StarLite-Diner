# Tea unit exports

One static chrome tea urn with rose base, authored through Pixelorama MCP.

- `tea-unit.png`: complete native 24×32 prop.
- `tea-unit-body.png`, `tea-unit-shadow.png`: same-frame body and contact-shadow components. Draw shadow then body to reconstruct the composite exactly.
- `tea-unit-atlas.json`: Aseprite-compatible metadata referencing `tea-unit.png`, one 1,000ms static frame.
- `manifest.json`: source paths, native geometry, palette, frame/tag, component order and verification.

Editable source, recipe, palette and 6× preview: [tea unit source](../../../../../assets/pixelorama/tea-unit-review/README.md).

The (12, 29) art base point marks visual worktop contact. Gameplay anchor, collision and interaction are unset. This file family does not implement a drink station or change the game routes.
