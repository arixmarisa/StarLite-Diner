# Customer family exports

Two customer bases, three outfits each, four directions, idle/four-frame walking/static seated poses: **72 frames per base, 144 total**. Native frames stay 16×24. [Editable Pixelorama sources, recipes and instructions](../../../../../assets/pixelorama/customer-v1/README.md) retain ten semantic layers, tags and approved palettes. Approved front-review assets are preserved exactly. No eating or other action animations or appearance generator are included. The [main-game visit test](../../../src/game/customers/README.md) now consumes these existing sheets/poses without changing source art.

`manifest.json` links the 96×288 family sheets, atlases, masks and previews. Rows are outfit then south/west/east/north; columns are idle, walk 1–4, seated. Atlas frame indices and tag ranges are zero-based. Native Pixelorama tags are one-based. Walking uses 8 fps; idle duration is 500 ms and walk duration is 125 ms. Seated tags are static single-frame poses. Source references in the manifest identify repository files, not public HTTP routes.

Walking foot anchor is (8, 23); seated hip anchor is (8, 19). The seated upper anatomy shifts down one pixel without resizing. `furniture-fit.json` and `seated-furniture-context.png` demonstrate native chair/stool/booth fits, including foreground occlusion and dangling stool feet. They retain their art-fit handoff status; the main-game adapter now adopts the chair/stool hip points and foreground crops for its limited sitting test; the main adapter also defines native straight/curved-booth attachments for the user-confirmed capacities.

`recolor-map.json` lists visible shade/base/highlight coordinates in each local 16×24 frame. Offset by its `sheetRect` for the family sheet. Six roles have matching white/transparent `*-mask.png` eligibility masks and full `*-layer.png` material sheets. Neutral outlines/eyes/buttons stay excluded; full layer sheets may contain fixed outlines and hidden pixels, so recolor using the masks/tone coordinates.

The live renderer hides feet/lower legs in north/south seated stool views by clipping below hip row 19 (visible rows 0–19). East/west side views retain the full bent-leg pose, with feet dangling four native pixels below the hip. The full 16×24 frame and seat anchor are preserved. Standing/walking and non-stool seats remain unclipped. Original sheet pixels, layers, masks and furniture-fit previews stay intact; this changes runtime visibility only.

`part-selection.json` partitions each frame's source commands into independent head, top (including sleeves/hands/undershirt/buttons), bottom (including exposed skin legs), shoes and shadow. Select matching direction/state/step across parts; hand/calf tokens use the chosen head's skin ramp. This enables future wardrobe composition beyond the three demonstrated presets without adding a generator here. All 144 originals reconstruct exactly; 96 cross-outfit assemblies were checked in memory without exporting extra variants.

Idle/seated previews show outfits as rows and south/west/east/north as columns at 8× nearest enlargement. The `*-motion-preview.png` files are valid four-frame APNGs at 8 fps, including per-outfit previews and the 768×432 combined view (male directions left, female right). Native assets remain independent game sprites, not a flattened room image.
