# Individual pancake-batter sprite

`pancake-batter.png` and the identical native atlas are 12×10. This raw cream oval is an individual grill item, separate from the stock bowl/ladle. It uses the same native pixel density and kitchen palette as the existing individual patty and sausage sprites.

Editable four-layer source, palette, static frame/tag, recipe and 10× preview are retained in [the source package](../../../../../assets/pixelorama/grill-food-v1/README.md). `verification.json` records saved-ZIP/PNG equality and native pixel QA. Runtime placement and shared contents are owned by the game; no timing or cooking state is painted into this asset.
