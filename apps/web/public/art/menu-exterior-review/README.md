# Menu exterior review exports

**Art and preview only; not integrated.** The static 384×216 background depicts the selected low pink/chrome Starlite Diner at blue hour with warm windows/neon and a quiet roadside forecourt. It is a main-menu illustration, not a gameplay exterior.

`menu-exterior.png` is the fully opaque background only. `start-comparison.png` is a derived review with the unchanged existing 96×28 Start sprite overlaid at (144,148). The button remains a separate game/UI asset; no Start pixels are baked into the background. Files ending `-preview.png` are exact 3× nearest enlargements (1152×648).

`manifest.json` records native bounds, static metadata, source paths, layer names, palette and the proposed button-safe region. It does not activate a loader, route, collision or interaction contract. [Editable Pixelorama sources and rebuild instructions](../../../../../assets/pixelorama/menu-exterior-review/README.md) retain the nine-layer background, two-layer review and 36-swatch palette. Live menu integration and responsive background behavior await approval.
