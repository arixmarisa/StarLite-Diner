# Compact grill ingredient exports

Three independent 8×12 native PNGs: `patty-stack.png` shows three raw patties, `sausage-pile.png` shows three plain sausages, and `pancake-batter.png` shows one steel batter bowl with ladle. Their visible width is six native pixels, suitable for the shared compact 8px-wide ingredient spots.

`ingredient-piles-atlas.png` is the 24×12 native atlas. `ingredient-piles-atlas.json` and `manifest.json` retain frame/source/tag and illustrated quantity metadata. `verification.json` records actual saved-Pixelorama-cel/PNG equality and pixel QA. The 10× preview is for review only.

Editable six-layer source, fourteen-swatch palette, recipes and source measurements are in [the source package](../../../../../assets/pixelorama/grill-ingredient-piles-v1/README.md). Parent room metadata supplies the same sprites and positions to normal and zoomed views. Artwork quantities do not implement inventory or cooking state. Previous ingredient sources are preserved.
