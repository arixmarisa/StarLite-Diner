The editable [Pixelorama source and recipes](../../../../../assets/pixelorama/kitchen-milkshake-review/README.md) retain six role layers and the original 14-swatch palette. `verification.json` records source/PNG equality, complete populated cels, frame/tag retention and an unchanged foreign active project.
