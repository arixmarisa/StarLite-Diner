# Refined grill-food exports

`patty.png`, `sausage.png` and `pancake.png` are separate **12×7** native raw-food sprites. Fuller 10–11px-wide silhouettes and original kitchen colors make the pieces more legible while fitting the two-row grill experiment. These are individual pieces, distinct from the counter's illustrated supply piles.

`grill-food-atlas.png` is 36×7; `grill-food-atlas.json` records spatial crop rectangles and the source's single static frame/tag. `manifest.json` lists the independent exports; `verification.json` records saved Pixelorama ZIP/PNG equality and pixel QA. `grill-food-preview.png` is exact 10× for review only.

Editable six-layer native source, palette and reproduction recipe: [source package](../../../../../assets/pixelorama/grill-food-v2/README.md). Slot capacity, front/back placement, rendering and lifecycle belong to the game adapter. No cooked/burnt variants, inventory or food-state animation are included.
