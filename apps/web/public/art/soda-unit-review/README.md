# Soda fountain exports

One compact three-tap front-of-house soda dispenser, matching the approved booth palette and native density. Native frame: 32×40, transparent. The cream header and pink/chrome cabinet contain no logo or readable label.

Editable source, palette and Pixelorama recipes: [soda source](../../../../../assets/pixelorama/soda-unit-review/README.md). `soda-unit.png` is the complete native image. `soda-unit-shadow.png` then `soda-unit-body.png` reconstruct it exactly at a common origin; every image is 32×40. `soda-unit-atlas.json` provides Aseprite-compatible metadata for the same native PNG, with one 1000ms static frame and named tag. `manifest.json` documents dimensions, components, palette and saved-source QA.

These are static artwork exports; gameplay placement, collision and dispensing behavior remain undefined. The source retains five named layers, the original 14-swatch booth palette and an exact 6× preview.
