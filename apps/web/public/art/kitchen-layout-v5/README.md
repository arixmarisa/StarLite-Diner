# Tight shared grill viewport

The playable kitchen and station use the same `layout.json` world objects. `stationViews.grill` defines viewport `(104,36,128,50)` and a compact 24×14 ingredient area beside the grill. Three 8×14 tray spots contain a three-patty pile, three plain sausages, and one bowl/ladle. `illustratedQuantity` is art metadata, not stock state.

`kitchen-layout.png` / its 2× preview and `grill-station-view.png` / its 9× preview are derived review images, not independent runtime backgrounds. Editable sources, palette, static tags and reproducible Pixelorama recipes are in [the source package](../../../../../assets/pixelorama/kitchen-layout-v5/README.md). Saved-source, crop and PNG checks are recorded in the two verification JSON files.

Room geometry, grill/counter scale, doors and existing interaction behavior stay intact. The old single-food and wider camera versions are preserved.
