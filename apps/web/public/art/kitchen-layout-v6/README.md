# Two-row shared kitchen exports

The room retains the tight station viewport and existing equipment/ingredient-counter placement. The revised grill image keeps its native 96×40 exterior, with a 85×15 cooking area for two rows of individual food.

`layout.json` supplies the same static room objects to both views. Runtime grill food comes from the shared `GrillContents` collection and `grillFoodInstances` registration; it is not baked into `kitchen-layout.png` or `grill-station-view.png`. Their enlarged PNGs are derived art previews only.

Editable Pixelorama sources, recipes, original-art preservation and real implementation limits: [source package](../../../../../assets/pixelorama/kitchen-layout-v6/README.md). Saved-source/PNG and exact room-crop checks remain in the verification reports.
