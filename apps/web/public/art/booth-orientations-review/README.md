# Booth orientation review exports

One new above/below booth candidate, authored through Pixelorama MCP, with the approved left/right original shown beside it for review.

- `booth-above-below.png`: native 80×104 transparent candidate.
- `booth-above-below-atlas.png` and `.json`: the same static frame and named tag, exported by Pixelorama.
- `orientations.png`: native 176×112 comparison, original left and candidate right.
- `manifest.json`: source paths, dimensions, review placements and limits.

The editable eight-layer candidate and two-layer comparison are in [the source directory](../../../../../assets/pixelorama/booth-orientations-review/README.md), alongside the palette and 6× preview. Use nearest-neighbor enlargement and integer coordinates. These files are review exports only; no application route loads them, and gameplay geometry remains undefined.
