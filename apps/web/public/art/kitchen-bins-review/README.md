# Kitchen empty-bin exports

One approved stainless-bin family in two empty arrangements, authored through Pixelorama MCP. All source pixel sizes are native and use the original booth/grill palette.

- `rear-toppings-rail.png`: 56×40 frame with a 48×24 counter mount and three bins.
- `prep-bins-insert.png`: 72×40 frame with a 64×24 mount and four bins.
- Each arrangement has `-mount.png` and `-bins.png` components; compose in that order at the same origin.
- `steel-empty-bin.png`: reusable 12×14 bin component, pixel-identical to every repetition.
- Each `-atlas.png` / `-atlas.json` pair is the same single native frame and named static tag.
- `bins-counter-preview.png`: 144×56 native comparison using unchanged accepted counter modules.
- `manifest.json`: source paths, native geometry, art attachments, tags and review limits.
- `verification.json` / `hole-verification.json`: saved-source, repetition, seam, reconstruction and pixel QA results.

Editable sources, recipe and 6× review PNGs: [kitchen bins](../../../../../assets/pixelorama/kitchen-bins-review/README.md). Use nearest-neighbor sampling and integer positions. The two inserts differ by arrangement, never by bin scale.

Both are deliberately empty. The interior rectangles are art-only placement data; no capacity, food assortment, collision, anchor or interaction behavior is implemented.
