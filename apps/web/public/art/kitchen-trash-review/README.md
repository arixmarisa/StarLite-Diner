# Kitchen trash-can exports

One fixed-view lidded stainless kitchen trash can with an inset dark opening, foot pedal and small rose badge. All native PNGs share a transparent 24×32 frame and origin.

- `kitchen-trash.png`: complete review composite.
- `kitchen-trash-body.png`: neutral main object.
- `kitchen-trash-shadow.png`: separate contact shadow.
- `kitchen-trash-atlas.png` and `.json`: one static frame/tag.
- `manifest.json`: source/palette references, native geometry, layer/frame metadata and art-only limits.
- `verification.json`: native saved-source/export, palette/frame/cel, component and silhouette results.

Draw shadow then body to reproduce the composite exactly. Keep nearest-neighbor enlargement and integer coordinates. The [editable source and recipes](../../../../../assets/pixelorama/kitchen-trash-review/README.md) retain four role layers, the original 14-swatch palette and a 6× preview.

No contents, animation or gameplay integration is included. Anchor, collision and interaction are unset; do not infer them from alpha pixels. Visual user acceptance is pending.
