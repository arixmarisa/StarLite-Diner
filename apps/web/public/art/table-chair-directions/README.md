# Existing up/down table chairs

`direction-manifest.json` points to the original reusable `chair-north` (up) and `chair-south` (down) sprites, each 16×24, and their existing source atlas rectangles. No duplicate game chair images are added. [Editable review sources](../../../../../assets/pixelorama/table-chair-directions/README.md) retain layered Pixelorama files, palette, recipe and verification.

`comparison.png` is the 40×32 review composition; `comparison-preview.png` is exact 12×, **up on the left, down on the right**. `table-context.png` is a 64×96 composition with the down-facing chair above the native 48×48 horizontal table and the up-facing chair below, both facing inward. Its preview is exact 6×. All objects are placed at their original pixel size. Use the referenced individual sprites in the game/editor; these compositions demonstrate direction and draw order.
