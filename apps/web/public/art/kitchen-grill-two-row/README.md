# Two-row grill exports

Native 96×40 room grill with a 85×15 cooking surface at `(5,7)`. Exterior size and counter attachment profile are unchanged. Native body/shadow/main PNGs and layered Pixelorama source are retained; [source and recipe](../../../../../assets/pixelorama/kitchen-grill-two-row/README.md).

The game uses six logical columns, each with back/front positions. Food is rendered dynamically over this empty surface; no grid or food is baked into the grill. `verification.json` records saved-source equality, unchanged exterior pixels and the exact counter join.
