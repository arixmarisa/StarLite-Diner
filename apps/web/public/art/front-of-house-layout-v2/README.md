# Reviewed dining room runtime content

`layout.json` is the integrated version of the user's editor draft: 624×432 native
pixels, 335 independent runtime instances, 84 seats and rebuilt doorway, furniture,
depth and approach metadata. Existing individual PNGs remain the runtime textures.
`layout.png` is a derived visual reference only.

The [source package](../../../../../assets/pixelorama/front-of-house-layout-v2/README.md)
retains the uploaded draft, deterministic metadata translator, editable eight-layer
Pixelorama project, palette, static frame/tag metadata and exact 2× preview.
Earlier room maps and original assets are preserved. `/design` begins at this
layout and accepts previous compact-baseline JSON drafts.
