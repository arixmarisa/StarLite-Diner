# Horizontal rectangular table exports

One camera-correct horizontal view of the v1 rectangular table, authored through Pixelorama MCP. The new 48×48 transparent frame contains a 33×26 laminate/rim and 31×24 cream interior, exactly transposing the original 26×33 and 24×31 material dimensions. Chrome height and the upright pedestal are redrawn for the fixed view.

- `table-horizontal.png`: native review composite.
- `table-horizontal-atlas.png` and `.json`: the same static frame and tag.
- `table-comparison.png`: 96×56 comparison, existing original left and horizontal view right, both at native 1× with aligned floor baselines.
- `manifest.json`: source paths, exact material measurements, frame state, comparison placements and review limits.
