# Compact kitchen bin exports

`rear-toppings-rail.png` is 48×32 with a 40×18 mount at `(4,10)`; `prep-bins-insert.png` is 56×32 with a 48×18 mount at the same origin. Both use the accepted compact-counter depth. Their seven repeated empty bins are pixel-identical 8×10 components.

The corresponding `*-mount.png` and `*-bins.png` files reconstruct each complete insert at their original frame origin. `steel-empty-bin.png` is a reusable derived crop. Manifests, per-source static atlases, geometry and verification retain native dimensions; no game capacity or interaction contract is asserted.

Editable four-layer `.pxo` sources, palette, drawing recipe and 6× previews are in [the source package](../../../../../assets/pixelorama/kitchen-bins-v3/README.md). The parent rollout supplies room placement and integration. Original artwork remains preserved.

Current integration: this compact art is used by `kitchen-layout-v3` in the playable kitchen and design library. Runtime movement/collision and door transitions remain engine-owned; the player is unchanged. Earlier sources are preserved.
