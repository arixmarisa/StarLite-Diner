# Stainless kitchen counter exports

One approved-to-create counter family, authored through Pixelorama MCP and awaiting visual review. All PNGs retain native dimensions; use integer placements and nearest-neighbor enlargement.

`manifest.json` lists11 independent modules and their exact source rectangles in the160×160 atlas. The source and its Aseprite-compatible static-frame metadata share the `kitchen-counter-static` tag. `kitchen-counter-preview.png` is a176×128 native-scale module-join demonstration; its6× review export lives beside the editable sources.

Horizontal tops are16×24 and fronts16×16. Vertical tops/near facades are24×16. The complete side view is24×48. End caps are16×40. Square top elbows are24×24 with separate facades; lips are derived16×4 and4×16 crops. Refer to the [source guide](../../../../../assets/pixelorama/kitchen-counter-review/README.md) for the precise two corner connections, repeats and reproduction/verification recipes.

The original14-swatch palette, four material layers, native source and editable two-layer join preview remain in the repository. No engine collision, interaction, anchors, room assembly or application integration is asserted.
